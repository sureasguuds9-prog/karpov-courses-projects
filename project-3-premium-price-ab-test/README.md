## Бизнес-задача

Проверить, увеличивает ли новая цена выручку на пользователя без недопустимого снижения конверсии.

## Методика

- единица анализа — пользователь, а не транзакция;
- перед основной проверкой оцениваются качество данных, баланс групп и две контрольные группы между собой;
- конверсии проверяются z-тестом долей;
- средняя выручка проверяется t-тестом Уэлча;
- ARPPU используется только для объяснения механики результата, а не как главный критерий запуска.

## Решение для бизнеса

Сохранить текущую цену. Следующий тест проводить на более узко определённых странах и платёжных системах, проверить меньший шаг повышения и увеличить период наблюдения для повторных платежей, оттока и LTV.

## Ограничения

- единицы выручки в исходных данных не подписаны;
- в транзакциях есть служебные строки, локальные расхождения и смешанный формат дат;
- короткое окно не позволяет оценить долгосрочный LTV и отток.
