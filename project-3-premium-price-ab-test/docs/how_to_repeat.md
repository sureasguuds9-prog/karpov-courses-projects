# Как повторить проект 3

1. Перейти в папку `project-3-premium-price-ab-test`.
2. Установить библиотеки:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Открыть `notebooks/project_3_variant_3.ipynb`.
4. Выполнить «Выполнить все ячейки».
5. Проверить баланс групп, A/A-контроль, таблицу CR/ARPU и доверительные
   интервалы.

Ключевые решения:

- единица анализа — пользователь;
- транзакции сначала агрегируются по `group, uid`;
- общая выручка берётся из `users.total_revenue` после reconciliation;
- даты транзакций не используются как фильтр из-за смешанного формата;
- ARPPU не является основной метрикой решения, поскольку считается только
  среди уже оплативших пользователей.
