# Продуктовый дашборд двух сервисов в Apache Superset

Учебный BI-проект Karpov.Courses для мониторинга продуктового состояния ленты
новостей и сервиса сообщений. Дашборд помогает сравнить активность двух
сервисов, оценить их пересечение и понять, какие группы пользователей чаще
отправляют сообщения.

[Открыть дашборд в Superset](https://superset.lab.karpov.courses/superset/dashboard/8835/)

> Дашборд размещён на учебной платформе Karpov.Courses, поэтому для просмотра
> может потребоваться авторизация.

## Аналитические вопросы

- Как меняется дневная активная аудитория ленты и мессенджера?
- Какая доля пользователей ленты также отправляет сообщения?
- Пользователи какого пола отправляют больше сообщений?
- Какие возрастные группы активнее общаются?
- Как показатели меняются за выбранный период?

## Состав дашборда

| Блок | Что показывает |
|---|---|
| DAU сервисов | Уникальных активных пользователей каждого сервиса по дням |
| Взаимодействие сервисов | Долю пользователей ленты, которые также отправляли сообщения |
| Сообщения по полу | Количество отправленных сообщений по полу отправителя |
| Сообщения по возрасту | Количество отправленных сообщений в шести возрастных группах |
| Период анализа | Нативный фильтр Superset, связанный со всеми графиками |

Возраст разбит на интервалы `до 18`, `18–24`, `25–34`, `35–44`, `45–54` и
`55+`. Такое представление читается лучше, чем отдельный столбец для каждого
возраста.

## Логика метрик

- **DAU** — число уникальных пользователей, совершивших хотя бы одно действие
  в соответствующем сервисе за день.
- **Сообщения по полу и возрасту** — число событий отправки сообщения, а не
  число пользователей. Поэтому графики отвечают на вопрос об общем объёме
  переписки внутри группы.
- **Доля пользователей ленты в мессенджере** рассчитывается на сопоставимом
  временном интервале; знаменателем служат активные пользователи ленты.

При интерпретации портрета аудитории важно не путать объём сообщений с
интенсивностью общения одного пользователя: более крупная группа может
отправить больше сообщений только из-за своего размера.

## Что улучшено после ревью

- добавлены понятные названия осей;
- убраны лишние легенды у графиков с одной серией;
- технические подписи вида `MAX(...)` заменены пользовательскими названиями;
- добавлен фильтр периода анализа;
- добавлены графики по полу и возрастным группам;
- графики собраны в три аккуратных ряда по два элемента;
- проверена работа фильтра на всех визуализациях.

## Ограничения

- Последняя дата в учебных данных может быть неполной, поэтому её снижение
  нельзя автоматически интерпретировать как ухудшение продукта.
- Для вывода о том, какая группа общается интенсивнее, дополнительно нужна
  нормированная метрика: сообщений на одного активного отправителя.

## Инструменты

Apache Superset, ClickHouse, SQL, продуктовые метрики и когортно-сегментный
анализ пользовательской активности.
