# 2. Первый дашборд

## Задания

1. Доделать основной дашборд ленты за весь период и оперативный дашборд за текущий день.
2. Добавить ключевые метрики, полезные срезы и показатели активности на пользователя.
3. Построить дашборд взаимодействия ленты и мессенджера: общая активная аудитория, пользователи только ленты и дополнительные продуктовые вопросы.
