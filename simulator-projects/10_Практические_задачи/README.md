# 10. Практические задачи

В личном кабинете блок содержит семь дополнительных задач. Отдельные пользовательские решения, однозначно относящиеся к этому блоку, локально не найдены.

Папка оставлена как индекс для будущего пополнения. Связанный SQL-проект по сервису доставки находится в [дополнительных проектах](../Дополнительные_проекты/SQL_аналитика_доставки/), потому что он относится к другому симулятору и не должен ошибочно считаться решением этого урока.
