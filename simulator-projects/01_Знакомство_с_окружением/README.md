# 1. Знакомство с рабочим окружением

Вводный блок знакомит с инструментами симулятора:

- ClickHouse — источник учебных событий;
- Redash — SQL-запросы и быстрая проверка метрик;
- Apache Superset — дашборды;
- JupyterHub — Python-ноутбуки;
- GitLab — сдача кода и merge request;
- Airflow — расписание ETL и отчётности.

Отдельного программного решения для этого урока не требуется. Связанные файлы распределены по следующим папкам курса.
