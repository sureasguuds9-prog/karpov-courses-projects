# 7. Построение ETL-пайплайна

## Задание

Ежедневно обрабатывать данные за предыдущий день:

1. Параллельно посчитать пользовательские метрики ленты и мессенджера.
2. Объединить их на уровне пользователя.
3. Построить отдельные агрегации по полу, возрасту и операционной системе.
4. Записать результат в таблицу ClickHouse с ежедневным дополнением.

## Решение

- [Airflow DAG](yaroslav_zinchenko_daily_etl.py)
- [Пример переменных окружения](.env.example)

DAG содержит отдельные задачи извлечения, объединения, трёх агрегаций и загрузки. Пароли удалены из публичного кода и передаются через окружение.
