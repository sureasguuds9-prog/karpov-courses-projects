# 8. Автоматизация отчётности

## Задание 1 — отчёт по ленте

Ежедневно в 11:00 отправлять в Telegram:

- текст с DAU, просмотрами, лайками и CTR за предыдущий день;
- графики динамики метрик за семь полных дней.

[Код отчёта по ленте](yaroslav_zinchenko_feed_report.py)

## Задание 2 — отчёт по приложению

Собрать бизнес-ориентированный отчёт по приложению как единому целому: общая аудитория без двойного подсчёта, лента, мессенджер, пересечение сервисов, динамика и файлы с деталями.

[Код отчёта по приложению](yaroslav_zinchenko_app_report.py)

Оба DAG используют `REPORT_BOT_TOKEN` из переменной окружения. Токен в репозитории не хранится. Локальная отправка текста, изображения и CSV проверялась; появление DAG и успешный запуск в учебном Airflow следует проверять отдельно.
