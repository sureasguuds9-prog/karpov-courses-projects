# 3. Анализ продуктовых метрик

## Задания

1. Сравнить Retention пользователей из рекламного и органического трафика.
2. Рассчитать Retention заданной когорты и проверить расчёт вручную.
3. Исследовать удержание пользователей, привлечённых рекламной кампанией.
4. Найти общий признак пользователей, потерявших доступ к ленте в день падения аудитории.
5. Построить недельную динамику новых, старых и ушедших пользователей.
