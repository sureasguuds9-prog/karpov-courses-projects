# 5. Sample size MDE

## Задания

1. Смоделировать влияние алгоритма рекомендаций на просмотры и лайки методом Монте-Карло.
2. Выполнить не менее 20 000 симуляций и оценить статистическую мощность.
3. Пересчитать мощность после снижения порога просмотров с 50 до 30.
4. Изменить длительность эксперимента с одной недели на две.
5. Сравнить анализ всей аудитории с анализом пользователей, на которых алгоритм мог повлиять.

В лекции блока также рассматриваются размер выборки, MDE и бакетное преобразование.
