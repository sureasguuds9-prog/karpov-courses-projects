# Оценка эффективности флэшмоба в ленте

Учебный проект модуля «Прогнозирование метрик» курса «Симулятор аналитика» Karpov.Courses.

## Краткий вывод

Во время флэшмоба 10–16 июля 2026 года выросли просмотры, CTR и число уникальных просматриваемых постов. Убедительного изменения DAU и числа новых постов не обнаружено. После завершения мероприятия устойчивый дополнительный эффект визуально не сохраняется.

| Метрика | Средний эффект в сохранённом запуске | Интерпретация |
|---|---:|---|
| DAU | около +1 тыс. пользователей | интервал включает ноль |
| CTR | около +0,7 п.п. | статистически убедительный рост |
| Просмотры | около +656 тыс. в день | статистически убедительный рост |
| Новые посты | около +8 в день | интервал включает ноль |
| Уникальные просматриваемые посты | около +80 в день | статистически убедительный рост |

> `tfcausalimpact` использует вероятностное приближение, поэтому численные оценки могут немного меняться между запусками.

## Бизнес-задача

Оценить, изменил ли флэшмоб активность пользователей и сохранился ли эффект после его окончания.

## Данные и метод

- источник — учебная таблица `simulator_20260720.feed_actions`;
- одна строка витрины — один календарный день;
- период до воздействия — 30 мая–9 июля;
- период воздействия — 10–16 июля;
- метод — байесовская структурная модель временного ряда через CausalImpact.

Модель оценивает контрфактическую траекторию: какими могли быть метрики без флэшмоба. Эффект равен разнице между фактом и прогнозом.

## Ограничения

- контрольного ряда нет, поэтому причинный вывод слабее результата A/B-теста;
- предполагается отсутствие других крупных одновременных изменений;
- дата создания поста приближённо определяется по его первому появлению в событиях;
- долгосрочный эффект оценивается по короткому периоду после мероприятия.
