# Оценка эффективности флэшмоба

Учебный проект по модулю **«Прогнозирование метрик» курса «Симулятор аналитика» Karpov.Courses**.

## Задача

Оценить, изменил ли флэшмоб 10–16 июля 2026 года активность пользователей ленты.

## Что внутри

- `notebooks/flashmob_causal_impact.ipynb` — короткий воспроизводимый анализ;
- `data/flashmob_daily_metrics.csv` — обезличенная дневная учебная витрина;
- `sql/flashmob_daily_metrics.sql` — запрос построения витрины из `feed_actions`;
- `requirements.txt` — зависимости.

## Метод

Для DAU, CTR, просмотров, новых постов и уникальных просматриваемых постов строится контрфактический прогноз с помощью CausalImpact. Пре-период — 30 мая–9 июля, период воздействия — 10–16 июля.

## Главный вывод

Флэшмоб увеличил глубину потребления контента, но не дал убедительного роста DAU и числа новых постов. После окончания мероприятия устойчивого дополнительного эффекта не видно.

## Воспроизведение

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook notebooks/flashmob_causal_impact.ipynb
```

Датасет относится только к учебной среде Karpov.Courses и не содержит сырых пользовательских событий или секретов подключения.
